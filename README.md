# 短信通知

把手机上的短信，变成 Windows 桌面上的通知。验证码可以在通知上直接复制。

请只在安全的家庭网络或可信局域网里使用。校园网、公司局域网、公共网络和不可信网络都不适合。如果还不了解局域网，请先不要使用。

需要 Windows 10 或 Windows 11，以及一台安装了 [SmsForwarder](https://github.com/pppscn/SmsForwarder) 的 Android 手机。手机和电脑要在同一个局域网里。

## 第一次使用

1. 双击 `启动.bat`。
2. 先看网络安全警告。确认当前网络可用后输入 `y`。输入 `n` 会直接退出。
3. 还没有密钥时，窗口会进入新手教程。按提示输入数字，用 `y` 或 `n` 确认。教程会依次带你完成：
   - 在手机上安装 SmsForwarder；
   - 生成密钥；
   - 固定电脑的局域网地址；
   - 创建并启动电脑上的服务；
   - 在 SmsForwarder 里新建 Webhook 发送通道，填入窗口给出的地址和消息模板；
   - 在 Headers 里点「+」，Key 填 `Authorization`，Value 填窗口给出的 `Bearer` 开头的整段文字；
   - 点手机右下角绿色的测试按钮，电脑屏幕右侧应出现通知；
   - 新建转发规则，选择刚才的发送通道和对应卡槽，再点测试。
4. 第一次创建服务时，Windows 会弹出管理员授权，请选择允许。
5. 电脑右侧出现通知，就说明已经接通。

## 以后再打开

再双击 `启动.bat`。窗口会问要不要修改此前的配置。输入 `n` 会直接启动；输入 `y` 会再走一遍教程。

## 遇到问题

**手机显示测试失败，电脑没有通知**

回到 SmsForwarder 的发送通道，确认已经点过 Headers 旁边的「+」。Key 是 `Authorization`，Value 必须是 `Bearer`、一个空格、再加密钥，和窗口里的整段文字一致。改完后再点绿色测试按钮。

**手机一直连不上电脑**

确认手机和电脑在同一个网络。地址要使用教程里给出的局域网地址，不要填 `127.0.0.1`。`198.18` 或 `169.254` 开头的地址手机也访问不到。

**电脑没有弹出通知**

打开 Windows 的「设置 → 系统 → 通知」，确认允许通知。专注助手或勿扰模式打开时，通知可能被挡住。

**提示端口被占用**

打开 `config.json`，把 `port` 改成另一个端口，再双击一次 `启动.bat`。

## 卸载

双击 `卸载.bat`，并允许管理员授权。它会去掉开机自启、防火墙规则和正在运行的服务。

程序文件夹还会留在原地。确定不再使用后，可以手动删除整个文件夹。
